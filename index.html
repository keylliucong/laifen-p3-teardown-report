摘要：五条结论

先给判断，再给依据。所有数值标明证据等级；没有实测的，一律写“推断”。

1. 它是 P3 Pro 的同平台降本机

同双直线电机 L2、同三刀头结构、同 1000 mAh/3.8 Wh、同 IPX7。官方 差异集中在外壳（玻纤增强 PC vs CNC 铝合金）、刀网（冲压 vs 电铸）、续航（90 vs 100 min）。

2. 内部大概率沿用 T1 Pro 的机头方案

“压板 + 螺丝 + 双道硅胶密封圈”，双电机反向布置、经连杆带三组刀头。推断 依据同平台拆解与 L2 官方描述，是本报告最先应被本机证伪的一条。

3. 刀头易维护，机身内部不是

刀头磁吸、可单买；电池、PCBA、电机、密封件官方不供件，开壳即破坏 IPX7。推断 按 iFixit 口径 3/10，与主流封闭式小家电同级。

4. 公开资料仍有四个硬缺口

视窗怎么固定、电池一颗还是两颗、双电机怎么带三个刀头、电机与主板是焊还是插。待拆确认 这四项直接决定结构与可维修性结论。

一句话：这是一台“动力与切剃平台共用、外壳与刀网重新做”的产品，不是整机重做；判断共用件时，电机与刀头结构可以共用结论，刀网、外壳、密封件必须分开写。

03

双直线电机 L2

本质是音圈式线性谐振执行器：电磁推力直接作用在刀头往复件上，弹片储能、电磁力补损耗。

200 Hz 与 12,000 CPM 是同一个量

12,000 ÷ 60 = 200 Hz

但厂商的“次”如果指单程，一个完整周期含去、回两程，机械频率就只有 100 Hz。判别很便宜：加速度计贴刀头座看频谱主峰——200 Hz 表示“次”= 周期；100 Hz 表示“次”= 单程。

推断 本报告按“机械频率 200 Hz、每周期算一次”处理。

为什么必须是谐振驱动

200 Hz 下若靠电磁力硬推，电流与发热随频率线性上升；把工作点放在机械谐振附近，弹片储存的弹性能承担大部分往复能量，电磁力只需补摩擦、切割与涡流损耗，效率高一个量级。

官方称电机寿命 >500 h；金属弹片是疲劳件，维修场景下不单独供件。推断

A. 拆前通电可测（先测再拆，顺序不能颠倒）

#什么时候测看哪里 / 量什么预期范围不符意味着什么
A1整机通电、装刀头空载加速度计贴刀头座与壳体，采样 ≥10 kHz，FFT 看主峰主峰 200 ± 5 Hz；壳体峰 ≤ 刀头座的 1/5主峰 100 Hz → “12,000 CPM”的“次”是单程；壳体/刀头 >0.5 → 隔振失效或双电机失衡
A2同上，刀头可取下高速摄影（≥2000 fps）或激光位移计，对准刀片边缘，测单周期位移峰峰0.4–0.8 mm 峰峰；3 次离散 <5%<0.3 mm → 推毛/切不净；>1.0 mm → 加速度与功耗超标
A3满电、空载USB 功率计读输入功率；能拆后串电流表测电机支路整机 1.3–1.6 W；3.8 V 下每台 0.17–0.21 A偏高 → 效率低或续航标称乐观；偏低 → 两个电机可能不同时工作
A4空载、贴皮肤空载各一次声级计距 1 m，1/3 倍频程主峰 200/400/600 Hz 窄带纯音；55–65 dB(A)；贴皮肤 +3–5 dB主峰不在整数倍 → 另有激励源；宽带明显 → 刀片—刀网摩擦占主导

B. 拆到该步可确认（目视 / 量具）

#拆到哪看什么 / 量什么预期范围不符意味着什么
B1取下刀头，露出动子弹片形式（金属涡卷 / 板簧 / 塑料）、片数、自由长度与线宽金属涡卷，2–4 片对称塑料弹片 → “金属弹片”表述不实；单片 → 抗偏载差
B2打开侧盖，露出定子磁钢块数、尺寸、极性排布（N-S 相对 / Halbach）每侧 2–4 块；8–12 × 4–6 × 1.5–2 mm只有单侧磁钢 → 推力只有一半；“双电机”是两台而非双定子
B3看动子线圈匝数、线径、直流电阻（LCR 表）1–3 Ω/台；线径 0.2–0.4 mm电阻远超 3 Ω → 铜损大；匝数很少 → kF 低、电流需求高
B4取下刀网厚度与槽宽/孔径分开量（千分尺 + 显微镜）厚度 ≈55 μm；槽宽 0.1–0.2 mm只测厚度会误读；槽宽才是切净率关键
B5取下刀片刃角与刃口半径（显微镜侧视）刃角 20–30°；刃口半径 <5 μm刃角 >35° → 切割力显著上升；刃口圆钝 → 夹须
B6刀片与刀网装回刃口到刀网内侧的间隙 g（塞尺 / 显微）20–50 μm，且 g < 须径g >0.08 mm → 折须而非剪断；g 不均匀 → 局部切不净

A 组记测点位置、采样率、仪器型号、环境本底、重复次数；B 组记工具与放大倍数，并拍带标尺照片。缺任一项只能记“观测”，不能记“验证”。以上为机理估算与设计区间，不是实测。

04

三刀头与刀网

三组刀头分工：中置开放式长须刀先把长须切短，两侧穹顶短须刀贴根剃净。标准版与 Pro 的最大差异之一在刀网工艺。

已知

  • 布局：2 穹顶短须 + 1 开放式长须，条形往复。官方
  • 外刀网：冲压精钢 / 低镍不锈钢，Ra 0.23。媒体
  • 内刃：301 不锈钢，18 次冲压。媒体
  • 拆解视频可见网面为错列圆角长孔；短须动刀下有弹簧向外网预紧。媒体

未知

  • 标准版刀网厚度：中国官网 55 µm 的脚注指向 Pro；台湾渠道写 0.055 mm。待确认
  • 孔型尺寸、孔距、开孔率、倒角与毛刺方向。
  • 单条刀网的法向顺应行程、整头摆角、弹性预紧力。
  • 动刀牌号、硬度、镀层；长须刀材料。
不要直接引用 55 µm：中国官网把 55 µm 的量化脚注明确用在 P3 Pro 上；标准版用的是冲压刀网，和 Pro 的电铸刀网不是同一工艺。厚度必须本机测，或等官方标准版参数。

刀头是唯一官方可换件

磁吸连接，徒手可拔。官方配件页列 P3 Pro 刀头组件 199 元、替换刀刃 99 元起；未找到标明 LFESP3-P 的标准版刀头独立 SKU。媒体称 P3 与 Pro 刀头通用，但刀网工艺与厚度不同，能否互换要以安装间隙和驱动接口为准。待确认

双电芯：视频已见，仍待本机核

P3 标准版对比拆解视频里可见两颗电芯，作者称每块 500 mAh；整机标 1000 mAh / 3.8 Wh，最可能是两颗并联（对称布置、降内阻）。2026 年 5 月黑色批次的电芯型号、极耳连接与并联走线仍要拆开确认。拆解 待本机

充电与运行

5 V⎓1 A 是额定输入上限（约 5 W），不等于电芯充电电流。官方 1.5 h 充满、3.8 Wh，平均输入约 2.5 W 量级。支持手机 OTG 应急供电，说明 USB-C 口有反向供电路径。媒体

说明书两条容易漏的：正常运行约 10 min 自动停机；充电时不能运行。实测续航要把“定时停机”和“低电停机”分开累计。

密封与防水

IPX7 是“短时浸水”等级，不等于可长期泡水。对拆机报告来说，重点是密封点在哪、拆一次会不会永久失效。

  • D1 拆压板 / 密封圈：硅胶圈永久变形，原厂不单卖 → IPX7 永久失去。
  • D2 掀 PCBA：排线在弯折处最脆，拉断即断联。
  • D3 拆电池：双面胶固定，按不可拆评估；撬变形即鼓包/起火风险。
  • D4 撬 PC 卡扣：塑柱断裂无法修复，502 会发白且更脆。

碰了就报废

  • D5 碰刀网：55 µm 网一按就凹，不可复原；只吹气/软毛刷。
  • D6 拆电机 / 磁铁旁用铁工具：预紧力无法复现；强磁吸螺丝、划板、装反极性。
  • D7 静电：当场测不出，几周后隐性失效。
  • D8 电池区金属工具：刺穿软包 = 热失控，只用塑料撬片。

凡胶粘件一律按不可拆评估：电池按双面胶固定、视窗可能胶粘；加热分离视为不可逆，不假设能装回。D 编号与 FMEA 模块 v2 一致。

可换件 vs 必须返修

用户可换

  • 刀头 / 刀网 / 内刃：磁吸，官方单独售刀头，不碰密封面。
  • 刀头吸不住：多数是磁面铁屑，胶带粘净即可。
  • 充不进电：先换线换头、清洁干燥 USB-C 口。

必须返修

  • 电池衰减 / 鼓包：说明书列为不可更换；鼓包立即停用不充电。
  • USB-C 口松动 / 腐蚀、压感失效：要拆机并重做密封。
  • 噪音变大 / 震感增强：指向弹片疲劳或减振失效，模组级，手工复装无法恢复装配精度。
防水三级验证：L1 喷淋 → L2 浅浸 → L3 IPX7。拆过的机器只能从 L1 重新开始；报告不把“复装完成”写成“恢复防水”。新机先录噪音基线，是弹片疲劳唯一可用的早期指标。

资料缺口：只有拆机/实测能回答

公开资料能回答“它大概怎么做的”，不能回答“这台具体怎么做的”。以下问题不拆不测就没有答案。

拆机可回答

  1. 视窗材质与固定方式；拆下是否变形。
  2. 电池颗数、串并联、电芯型号与供应商。
  3. 双电机到三刀头的连杆拓扑与传动比。
  4. 电机与主板是焊还是插；双电机用几颗驱动。
  5. 密封圈数量、截面、材质；拆后是否永久变形。
  6. 螺丝规格、数量、是否定制、有无螺纹胶。
  7. PCBA 器件型号、板层数、有无测试点。

拆机也不够，要实测/台架

  1. 真实行程、负载下频率、推力-电流曲线。
  2. 电机弹片寿命与失效模式（>500 h 声明的试验条件）。
  3. 刀网厚度、孔型、刃角、切割效率。
  4. IPX7 复装后的实际密封性。
  5. 续航口径（80/90/100 min）在统一负载下的真值。
  6. 噪声频谱与振动传递路径。
  7. BOM 成本：没有公开报价与物料清单，只能做定性成本驱动分析。
本报告不回答：“值不值得买”“比 Pro 好多少”“能用几年”。这些需要统一样本的实测与长期可靠性数据，不是拆一台能得出的结论。
