# 剃须刀拆机调研

> 两台 599 元国产往复式剃须刀的拆前研究：徕芬 P3 标准版（LFESP3-P）与有色 MINI 5 PRO（YSFSW50-Z）。非官方独立研究；拆机由机主执行，本仓库提供预期、取证清单与对照口径，不代替实测。

**在线阅读**：<https://keylliucong.github.io/laifen-p3-teardown-report/>

## 两份报告

| 产品 | 路线 | 报告 |
|---|---|---|
| 徕芬 P3 标准版 | 双直线电机 L2，3 刀头，1000 mAh，187.1 g | [laifen-p3/](laifen-p3/) |
| 有色 MINI 5 PRO | 磁悬浮直线 14,000 RPM，5 刀头，420×2 mAh，约 117 g | [yoose-mini5pro/](yoose-mini5pro/) |

## 为什么放在一起

同价位、同 IPX7、同为往复式，但走的是两条路：

- **P3**：双电机反向对消 + 大电池 + 玻纤 PC 壳，拼减振与续航；
- **MINI 5 PRO**：单电机高频 + 五刀头 + 双电芯 15W 快充 + 合金壳，拼刀头面积与充电速度。

两份报告用同一套证据分级，方便横向比较；不要拿一台的拆解直接推另一台。

## 内容

每份报告包含：

- 产品基线与批次/口径冲突（包装 vs 官方 vs 渠道）
- 结构分层、BOM 树、可维修性评分（推断）
- 电机与刀头机理、可检验预测（A 拆前测 / B 拆机确认）
- 电气、电池、充电的自洽性核算
- 密封与 IPX7、湿态充电边界
- FMEA（使用期 F + 拆解引入 D）
- 合规/专利、竞品对照
- 拆机观察清单（必拍/必量/必记）与资料缺口

## 证据分级

| 标记 | 含义 |
|---|---|
| 官方 / 包装 | 品牌规格页、说明书、包装标签 |
| 拆解 / 媒体 | 第三方拆解、发布会、上手评测 |
| 推断 | 由同平台结构或物理关系推出，必须写依据 |
| 待确认 | 只有本机拆解或实测能回答 |

**规矩**：官方声明 ≠ 实测；同平台拆解 ≠ 本机拆解；推断不得改写成实测。找不到就写“未找到”。
