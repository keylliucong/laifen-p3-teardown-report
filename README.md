# 徕芬 P3 标准版（LFESP3-P）拆机研究报告

> 非官方独立研究。拆机由机主执行；本仓库提供拆前研究、结构预期、取证清单与对照口径，不代替实测。

**在线报告**：<https://keylliucong.github.io/laifen-p3-teardown-report/>

## 这是什么

一台 599 元的双直线电机三刀头剃须刀，内部怎么做的？本仓库把公开资料（官网、说明书、同平台拆解、专利、标准）整理成一份可复核的拆机前研究：

- 产品基线与批次差异
- 结构分层、BOM 树（9 个一级件 / 约 34 个二级件）
- 双直线电机 L2 的机理、行程/推力/功率估算与 5 条可检验预测
- 三刀头与刀网：标准版与 Pro 的工艺差异
- 电气架构推断（以 T1 Pro 拆解为参照）
- 密封与进水路径、可维修性评分（3/10，推断）
- 合规条款（GB/T 4706.1-2024、GB/T 4706.9-2024、IPX7）
- 竞品对照与拆机观察清单（20 张必拍 / 10 项必量 / 10 处丝印）

## 五条结论

1. **同平台降本机**：同 L2 电机、同三刀头、同 1000 mAh；差异在外壳（玻纤 PC）、刀网（冲压）、续航（90 vs 100 min）。
2. **内部大概率沿用 T1 Pro 的“压板 + 螺丝 + 双道密封圈”**，双电机反向、连杆带三刀头——推断，待本机证伪。
3. **刀头易维护，机身内部不是**：电池、PCBA、电机、密封件官方不供件，开壳即失去 IPX7。
4. **四个硬缺口**：视窗固定方式、电池批次与并联、双电机到三刀头的连杆拓扑、电机-主板焊/插。
5. **先拍再拆**：按 `CHECKLIST.md` 的编号拍，回去才能回填成 v1.0。

## 证据分级

| 标记 | 含义 |
|---|---|
| 官方 | 品牌规格页、说明书、包装标签 |
| 拆解 / 媒体 | 第三方拆解、发布会报道、上手评测 |
| 推断 | 由同平台结构或物理关系推出，必须写依据 |
| 待确认 | 只有本机拆解或实测能回答 |

**规矩**：官方声明 ≠ 实测；同平台拆解 ≠ 本机拆解；推断不得改写成实测。找不到就写“未找到”。
